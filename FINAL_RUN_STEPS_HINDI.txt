HimRideG Final Run Steps
========================

1) Backend terminal:
   cd server
   npm install
   npm run dev

2) Frontend terminal:
   cd client
   npm install
   npm run dev

3) Chrome:
   http://localhost:5173

4) Backend health:
   http://localhost:5001/api/v2/health
